# CLIProxyAPI 本地服务插件

在管理器「工具」中打开。沿用原有服务路径、DPAPI 加密密钥及 `managed-cliproxy` / `managed-cliproxy-official` 供应商，不搬迁登录或数据。

支持状态、安装固定版本、启停、控制台、模型刷新、显式 API 测试、保存连接和密钥、两类专用供应商接入。测试会产生上游用量；安装会下载原有锁定版本。官方通道仍使用宿主的官方目录校验，不能把任意模型伪装成官方模型。

停用插件会关闭入口并阻止以后随管理器自启动；已经运行的服务及供应商保持原样。停止服务、移除接入是单独按钮。旧版兼容入口暂时保留，便于验收和回滚。插件不接管 CLIProxyAPI 的独立账户文件，也不删除程序或外部配置。

需要 Windows 原生宿主适配。`manager.html` 发布时由共享 `local-services/panel.html` 和 `panel.js` 装配，已安装包内页面自包含。
