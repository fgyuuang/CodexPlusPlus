# NewAPI 本地服务插件

在管理器「工具」中打开。沿用原有连接、DPAPI 用户令牌及 `managed-newapi` 供应商；不读取管理员 Cookie、数据库或 .env。

可连接远程 API，也可管理已有本机 Compose 项目。启动使用 `up -d`，停止使用 `stop`，不删除卷、不重建配置、不自动更新镜像。API 测试由用户明确点击，可能产生用量。

停用插件不停止独立服务，也不删除已接入的供应商。移除接入是单独操作；旧版兼容入口保留供验收与回滚。加入网关供应商池继续使用「供应商池」现有导入流程。

需要 Windows 原生宿主适配。`manager.html` 发布时由共享 `local-services/panel.html` 和 `panel.js` 装配，已安装包内页面自包含。
