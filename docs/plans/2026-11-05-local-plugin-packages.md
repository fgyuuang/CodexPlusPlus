# 独立本地插件包：实施门禁

- 用户授权：检查编译后继续修改，使本地能力可独立更新，减少后续上游合并。
- Module：本地插件打包、预览安装、备份更新与回滚工具；Structural decision：Refactor Backlog；Execution decision：Staged Refactor。
- 证据：第一阶段页面仍由 Rust include_str 嵌入，bundled 目录在宿主首次加载时重写；直接更新该目录无法保证重启后保留。上游已支持 user_scripts 下的独立管理器包，原生权限适配可授权 user 包。
- 行为契约：生成自包含包，安装到明确配置目录的 user_scripts/<固定 id>；默认只预览，显式 apply 才写。更新前完整备份，原包及其他插件不删除；校验路径、文件集、清单和 SHA256，拒绝符号链接及未知文件。回滚复用已验证的旧包安装流程。不能修改认证、供应商或 user_scripts.json，不能启停服务、重启应用。
- 预期文件：新目录 local-plugins 下脚本、定向测试、README；本计划和报告。脚本目标不超过 200 行，测试不超过 160 行，文档另计。工具基线不存在，先记录接口断言并用隔离临时目录测试。
- 禁止范围：正在发布任务 20261105-085252-0de45070 的任何冻结输入（crates/apps/assets/scripts 等），dist、依赖、服务及用户真实配置。local-plugins 与 docs/plans/reports 不在当前发布输入集合内，验证该事实后才写入。
- 最小步骤：先完成独立打包和可预览安装工具及测试；不在本轮冻结构建中修改宿主入口。产物在 output 内生成，实际安装在新版宿主成功交付并可用后进行。
- 已知边界：现有连接页按钮与 CLI 自动启动仍绑定 bundled key；独立包可以从自己的侧栏打开，但完全切换默认入口及自启动需要下一项宿主兼容变更。当前不能宣称所有本地代码或自动启动均已独立插件化。保留 bundled 的启用状态，工具不私自改变它。
- 验证：无网络的 Node 测试覆盖物化、完整性、默认预览、升级备份、回滚、损坏/越界/符号链接拒绝；保护原发布输入哈希。生产安装和真实界面验收单独记录。
- 回滚：不执行工具则没有生产变更；已安装的包可用旧备份回装，也可经管理器停用。禁止为了回滚删除账号或外部服务数据。新增范围或预算超限时重新门禁。
