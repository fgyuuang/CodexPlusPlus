## 官方登录与图片的兼容边界

v2 默认“借用网关 ChatGPT 登录给未登录 Codex”会写 live auth，与本地来源切换保持登录原字节冲突。整合版保留网关独立官方登录功能，但普通接入、刷新、关闭不借用、不创建或覆盖 Codex 登录。旧借用关系无法证明当前归属时停止复制/清除并明确提示分别重新登录，双方凭据保持原状。旧借用刷新入口同样拒绝，防止按 Team account_id 误认用户。

Codex 官方 gpt-image-2、缺失或空模型的内置生图仅接受唯一或明确选择的官方账号。失败不换官方账号，也不转第三方。未知模型需 Agent 接入页明确选择供应商；其他 Agent 的通用生图策略保留上游行为。日志不存提示词、图片或原始认证错误正文。

## 新网关父子来源与压缩

`/gw/codex` 的原生 UUID 必须由只读线程库或同一受信 app-server 证明，拒绝未知身份、多父、有环、跨对话和冲突 sessionId。临时 fork 和普通持久化 fork 分别处理，其他 Agent 和普通 CLI 缓存键不受原生线程规则误判。

根请求成功响应头确认后记录当前供应商；新根请求以 generation 清理旧绑定，阻止旧响应覆盖新选择。子请求只允许根来源中确实支持的模型，来源停用或删除时拒绝。根显式选择第三方后，子裸模型沿该来源；无此证明的官方裸模型仅接受唯一官方来源，失败不改账号或转第三方。压缩和子代理官方图片同样不能另选账号。

此绑定表示本进程已确认的网络来源，尚未发送的 UI 选择不视为已生效。新网关重启后须由根对话先发起请求重建绑定；此前子请求明确报错，不猜测来源。原有直连模式的完整父子谱系跟随规则保留，不能宣称两种模式的持久化行为完全等价。

## WorkBuddy

在 Agent 协作增加第四个原生 CLI 目标 WorkBuddy。支持自选绝对 CLI 路径和模型、固定目标 MCP 委派、流式结果、同一协作会话续聊，以及共享任务引擎的取消、超时和任务记录。旧三目标配置仅补一个默认停用的新目标，原有目标和任务不改。

Windows 任务由 Codex++ 宿主持有独占的 KillOnJobClose Job，在发送提示词前约束本次 CLI，取消、超时和正常退出均收回该任务的后代；无法隔离则不发送提示词，不能按进程名终止其他桌面任务。协作 MCP 刷新必须看到新增 delegate_to_workbuddy，旧十工具缓存不再误报就绪。

Windows 桌面发行包的 cli/bin/codebuddy 是 Node 脚本，使用现有 Node 显式传递单个脚本路径，不经过 shell，禁止把 WorkBuddy 桌面 EXE 当 CLI。进程隐藏、提示词通过 stdin、禁继承协作 MCP 防递归，保留 CLI 自身权限规则，不复制 Codex、网关或桌面凭据。

真实 CLI 探测已启动并返回标准 stream-json，但当前没有 CLI 登录，返回 Authentication required；退出码虽然是 0，结果事件为 error_during_execution/is_error=true。整合版据终止事件判失败，不能显示任务成功。真实模型成功、续聊和桌面登录桥复用尚未验收，现有 WorkBuddy 插件未修改。当前版本只集成直接 CLI，不把桌面登录状态伪装成 CLI 认证。
