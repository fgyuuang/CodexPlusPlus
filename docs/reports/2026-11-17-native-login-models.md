# 当前登录账号的原生模型目录

目标：Codex 及远程客户端继续使用当前登录账号的裸模型 ID，移除同一账号的重复限定项。

## 行为

- 在现有官方体验启用、设置中存在当前登录账号时，为 Codex 绑定生成只读原生目录投影。目录采用账号缓存、bundled/兼容目录的精确条目，不维护模型名称数组，不发网络探测请求。
- 原生裸模型固定使用当前登录账号的账号库引用，只有一个候选；不会因为供应商同名、账号调度首选不同或请求失败而进入供应商轮转。
- 当前账号的 `账号供应商 ID/模型` 不重复列出；已有默认值生成配置时使用裸 ID。旧聊天仍可用限定 ID 找回原账号，其他账号和供应商条目保留。
- 与原生模型同名的自动组改用 `codex-plus-auto/模型`。仍复用上游组展开、排序、粘性和候选流程；关闭自动组后显式入口报错，不改发默认模型。
- Codex 写入配置、网关请求与管理器选择器使用相同的原生目录投影；管理器区分“当前登录账号”和“自动组”。其他 Agent 及模型组编辑沿用原规则。
- 运行时投影不持久化到 gateway.json；切换登录账号时重写目录，不替换 auth.json。身份同步仅核对原生条目，不反复重建所有供应商目录。

旧的裸自动组名称从本次起代表当前登录账号；需要继续多家切换时选择“自动组”中的独立入口。旧的限定供应商/账号模型标识保持兼容。
