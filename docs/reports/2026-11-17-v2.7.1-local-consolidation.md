## 4. 上游覆盖与本轮必要调整

正式 2.7.0/2.7.1 的远程控制、加加、任务面板、供应商页、拓展市场分栏、主题修复、集中设置、Skills 原地更新/归档、压缩阈值和 Responses WebSocket 已合入。

1. **共享供应商编辑器**：上游已把编辑函数抽到 `relay-profile-editing.ts`。将本地 9 个修改过的 helper、17 个兼容 helper 并入共享实现，移除 App 内重复函数。生成的 42 分片和 React 使用同一份实现；保留上游页面结构。
2. **配置保留修正**：成员存在性按完整供应商 ID 集合判定；暂时缺少 URL/Key、候选过滤变化不删除现有成员和路由；确实删除的供应商仍会清理引用。相关回归继续执行实际 helper。
3. **运行时目录**：共享 helper 从宿主读取当前目录；注入 bundle 不再带入静态模型目录和大段 `base_instructions`。Codex 页复用桥接目录，避免陈旧目录及额外载荷。
4. **设置收敛**：管理器保留上游精简增强页，本地 Fast、快速启动、容量重试、额度继续、项目移动等开关集中到 Codex 设置页。保留配置字段及兼容，不恢复老页签。
5. **账号与协议类型**：从原账号库 auth 派生新增 `account_scope`；补齐上游 WebSocket 与本地容量重试/通道字段；模型元数据同时保留本地来源说明和上游图像能力。
6. **远程模型分页**：不再只取前 100 个模型；保持裸 ID、推理档位，遇重复游标明确失败，避免卡循环或悄悄截断。
7. **加加授权竞态**：用户输入携带 Principal；不同设备不混入当前插话，切换设备重建临时会话；权限取排队时与当前设备角色的较低值，移除后不保留写权限，异步查找结束后再次检查权限。定时输入默认只读。此修复针对运行时授权竞态，不代表完成所有模型提示注入与共享记忆场景的安全验收。
8. **本机服务连接**：禁止把本机服务密钥交给环境代理；保留同地址、同供应商身份、已有备用 Key 的回归。
9. **删除重复维护**：采用上游 Skills 实现（本地差异核对后仅为格式）；移除重复的老拓展/赞助商测试组，保留上游覆盖更多场景的版本；测试提取位置随共享模块迁移，实际行为断言保留。

本轮适配没有额外增加第三方依赖；上游 TLS 依赖与既有本地账号库/服务依赖分别保留。相对合并中间结果，Cargo.lock 只修正一行本地 workspace crate 版本，后续离线 locked 检查通过。原本地 Release `thin LTO / 16 codegen units` 设置保留，本轮没有靠降低发布优化来缩短检查，也未验证其性能取舍。
