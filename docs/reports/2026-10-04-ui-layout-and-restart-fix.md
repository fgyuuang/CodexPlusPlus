# v1.5.0 重启入口与会话布局回归修复

用户在使用本地合并版 v1.5.0 后报告：Manager 的重启按钮消失，Codex 最左侧出现大块
空白，右侧内容被裁切。实际运行目录为 `D:\pro\Codex++`；三个安装文件的哈希与本次
上游更新产物一致，确认问题发生在新版，而非旧副本。

## 原因与改动

1. `App.tsx` 中的重启按钮 JSX 被合并进 `syncProvidersNow()` 的异步操作，表达式没有
   进入 React 返回的视图。TypeScript 可以接受该表达式，因此类型检查未发现按钮消失。
   将原有按钮移回 `topbar-actions`，保留 Codex 工具模式、启动中禁用、用户点击确认以及
   `actions.restart("topbar")` 的原有调用边界。
2. 会话居中查找在滚动容器尚未出现时，对整棵文档进行 CSS 变量兜底查找。线程宽度
   CSS 变量可以继承，导致 `#root` 被当作聊天容器并设置 `max-width: 900px`。
   根容器留在缓存中，页面加载完成后仍保持受限宽度。把变量兜底限制在实际会话滚动
   容器或页脚子树内；缺少这些节点时返回空目标，等待真实内容加载。
3. 修改 renderer 分片后重新运行 `scripts/assemble-renderer-inject.mjs` 生成注入单体。

本次生产源码修改仅涉及 Manager 控件位置、会话容器查找及其生成产物；供应商协议、
路由、鉴权、官方账号和模型目录代码沿用已验收的上游合并态。

  被选为内容或输入框容器。原有旧版/新版内容锚点、页脚、窄容器自适应测试仍通过。
