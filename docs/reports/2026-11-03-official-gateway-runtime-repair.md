| 池内模型看起来连成超长一串 | 数据中是独立模型，界面重复显示内部供应商 ID。模型标签改显示真实模型名，完整路由保留在悬停提示；内部路由和账号身份不改。 |
| 关闭时不停启动及弹命令窗口 | 16:41:20–16:43:12 日志中有 649 个启动器 PID、705 次锁冲突和 638 次包激活；未取得启动锁的进程仍能调用 launch_codex。现在 Windows 非持锁启动器只聚焦 CDP 正常的现有窗口，退出期间拒绝，不启动、不覆盖持锁者状态。CLI 版本/帮助探测提前返回，未知 CLI 命令拒绝，旧 autostart 转交 Manager。 |
